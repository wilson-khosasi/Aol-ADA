# Aol-ADA

Case:   
- A computer hardware company has several warehouses, several delivery trucks, and several distributors/stores that sell its computer hardware.
- Every day, the company has to deliver goods from each warehouse to many customers using its trucks. The problems that need to be solved include finding the fastest delivery route, scheduling the trucks, assigning computer packages to each truck, and choosing the most efficient warehouse.
- If this is done manually, it will lead to high operational costs and longer delivery times. Because of this, an algorithm is needed that can optimize the hardware distribution process by using several algorithm design methods.

Chosen Problem:  
- Determine the fastest delivery route

Chosen Programming Language  
- C
